# Dataset Attribution

The raw dataset used for this project is the **IBM Telco Customer Churn** dataset.

* **Source:** Kaggle / IBM Community
* **Rows:** 7,043
* **Columns:** 21
* **License:** Apache 2.0 / Open Data Commons

To replicate the project, download the source file `WA_Fn-UseC_-Telco-Customer-Churn.csv` directly from Kaggle and load it into PostgreSQL under the table name `telco_churn.customer`.
